# Configuring the Product Page PDF Extension

To configure the extension, navigate to **Content > Product Page PDF > Configuration** in the left Admin Panel menu, or go to **Stores > Configuration** and select **Plugin Company > Product Page PDF** from the left side menu.

Using the extension's config screen you can modify its front-end settings and the PDF layout, content and design options as further explained in the following chapters.

It’s possible to configure the extension per store view using the dropdown menu at the top left corner of the page.

To save any changes made in the Product Page PDF settings, click the 'Save Config' button in the top right corner of the configuration page.
